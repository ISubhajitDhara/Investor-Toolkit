Privacy Policy

Last updated: 9 November 2026

This is a starter privacy notice for the current static website. Review and update it before public launch to reflect the actual hosting, analytics, advertising, forms, app SDKs and other services you enable.

Information stored in your browser

The learning app uses browser local storage to remember preferences and learning progress, such as saved lessons, completed lessons, language and theme. This information stays in the browser on your device and is not currently sent to an Investor Toolkit server.

Hosting and server logs

This website is intended to be hosted using GitHub Pages. GitHub may process technical information such as IP address and request logs as part of hosting and security. Refer to GitHub's current privacy documentation for details.

Analytics, advertising and third parties

No analytics, advertising pixels, account system, payment processor or contact form is included in this starter build. If any are added, this policy must be updated before they are enabled.

Children and contact

This educational website is intended for a general audience. A public contact channel has not yet been configured. Add a monitored contact email or form before launch if users need to contact the publisher.

Changes

This policy may be updated when the website or app changes. The effective date above should be revised whenever material changes are made.
